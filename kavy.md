# Kavya Patel — Personal Portfolio Website

A responsive single-page portfolio made with HTML5, CSS3 and vanilla JavaScript.

## Files
- `index.html` — website sections and content
- `style.css` — layout, responsive design, and animations
- `script.js` — mobile navigation, reveal effects, active nav, and email-form behavior
- `assets/Kavya_Patel_Resume.pdf` — résumé download
- `PROJECT_REPORT_TEMPLATE.md` — report content checklist

## Run locally
Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.

## Before submitting
1. Check all personal details and résumé information.
2. Replace GitHub profile links in project cards with each project's real repository URL when available.
3. Add a real photo if required by your faculty; currently the hero uses a designed initials avatar.
4. Test on mobile and desktop.
5. Create a public GitHub repository named `KavyaPatel_PortfolioWebsite` (or the exact name required by your faculty).
6. Upload all files, commit, and push.
7. In GitHub repository Settings → Pages, choose deploy from the `main` branch and `/ (root)` folder.
8. Wait for the published link, then test it.

## Contact form
This is a static GitHub Pages site. The contact form opens the visitor's default email app with a prefilled message; it does not store or send form data by itself.
